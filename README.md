# OrgSuite PWA Studio

Workplace PWA audit and packaging desk for PSE Management.

- Live site is deployed from this repository / Vercel project `orgsuite-pwa-studio`.
- Official store packaging still happens at https://www.pwabuilder.com/ using a public HTTPS URL.
- No Microsoft, Apple, or Google store credentials are stored here.

## Local

Open `index.html` or serve the folder over HTTPS.

## Security

Secrets stay in Vercel environment variables. This static app does not call private APIs.
